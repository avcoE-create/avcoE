# DSL Exam Practicals (AI&DS, 2026-27)

All 17 programs are written in C++ and are menu driven.

## How to run

Compile everything at once:

    ./build_all.sh          # creates ./bin/<program>

Or compile a single program:

    g++ 01_search/search.cpp -o search && ./search
